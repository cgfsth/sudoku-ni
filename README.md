# Sudoku NI

A calm, autumn-inspired Sudoku game with a responsive layout, optional dark mode, and helpful hints.

## Features

- Easy, medium, and hard puzzles
- Ten hints per puzzle
- Notes mode for tracking possible numbers
- Board checking and mistake feedback
- Pause/resume and a puzzle timer
- Light and dark themes, with the selected theme saved in the browser
- Responsive home page with a quick-start guide

## Run locally

Open `index.html` in a modern web browser. No build step or external dependencies are required.

## How to play

Fill the 9×9 grid so every row, column, and 3×3 box contains the numbers 1 through 9 exactly once. Select an empty square and enter a number using the on-screen number pad or your keyboard. Use Notes to record possibilities, and use a hint when you need help.
